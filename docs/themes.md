# Dynamic Theme Engine & Visual Customizer

## Theme Section Architecture
Themes in Nabrijan SaaS are built from JSON section blueprints rather than static HTML pages.

### Supported Section Types:
1. `HERO`: Promotional main banner with custom CTA title, subtitle, and button text.
2. `FEATURED_PRODUCTS`: Grid/carousel rendering store catalog products dynamically.
3. `BENEFITS`: Feature highlights bar (Fast COD delivery, authentic quality guarantee, support).
4. `CATEGORIES_GRID`: Category navigation showcase.
5. `NEWSLETTER`: Email signup subscription bar.

### Visual Customizer Features:
- Frame Viewport Switcher: Live toggles for Desktop (100%), Tablet (768px), and Mobile (375px).
- Drag and Drop / Reorder: Section sequence modification.
- Live Color & Style Palette: Real-time update of brand accent colors.
